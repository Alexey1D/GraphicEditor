\# Graphic Editor (Lab 2)



\## Description

This project is a simple graphical editor developed using C# Windows Forms and object-oriented programming principles.



The application demonstrates:

\- Inheritance and polymorphism (virtual methods)

\- Factory pattern for object creation

\- Separation of shape models and rendering logic

\- Extensible architecture without modifying existing code
